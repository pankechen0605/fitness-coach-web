# ChatGPT Review Prompt

将以下 prompt 发送给 ChatGPT，让它评估你的 GitHub 仓库。

---

## Prompt

请阅读这个 GitHub 仓库：[仓库链接]

**首先阅读 PROJECT_GOAL.md**，了解项目目标和约束。

然后进行结构评估：

### 1. 项目结构分析
- 评估当前目录结构是否合理
- 检查组件拆分是否合适
- 检查类型定义是否完整

### 2. 代码质量评估
- TypeScript 使用是否规范
- 组件是否过大或职责不清
- 是否有明显的代码重复

### 3. PR1.1 最小计划
基于当前状态，给出 PR1.1 阶段的最小实现计划：
- 需要创建哪些文件
- 数据适配层应该如何设计
- 如何为 PR1.2（本地 JSON 接入）做准备

### 4. 约束确认
请确认你的建议符合以下约束：
- ❌ 不推荐数据库
- ❌ 不推荐登录/认证系统
- ❌ 不推荐 SaaS/云同步
- ❌ 不推荐大重构
- ✅ 保持本地优先
- ✅ 保持 Mock 数据模式
- ✅ 保持深色主题 UI 方向

### 5. 输出格式
请用以下格式输出：

```
## 结构评估
[你的评估]

## 代码质量
[你的评估]

## PR1.1 计划
[最小实现步骤]

## 风险提示
[需要注意的问题]
```

---

## 使用方法

1. 将项目推送到 GitHub
2. 复制上面的 prompt
3. 将 `[仓库链接]` 替换为你的 GitHub 仓库 URL
4. 发送给 ChatGPT
