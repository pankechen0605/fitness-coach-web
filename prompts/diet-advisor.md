# Diet Advisor Prompt

## 任务

根据训练安排，给出饮食建议。

## 输入

- 训练日期
- 训练部位
- 当前热量摄入
- 用户饮食偏好

## 输出格式

```markdown
**饮食建议 - [日期] [部位]训练**

**训练前餐（训练前 2-3 小时）**
- [食物1]：[份量]，[热量] kcal
- [食物2]：[份量]，[热量] kcal
- 总热量：[总热量] kcal

**训练后餐（训练后 30 分钟内）**
- [食物1]：[份量]，[热量] kcal
- [食物2]：[份量]，[热量] kcal
- 总热量：[总热量] kcal

**蛋白质摄入建议**
- 目标：[体重] x 1.6-2.0g = [目标蛋白质量]g
- 当前：[当前蛋白质量]g
- 建议：[补充建议]

**水分补充建议**
- 训练前：500ml
- 训练中：200ml/15分钟
- 训练后：500ml

**注意事项**
- [注意事项1]
- [注意事项2]
```

## 考虑因素

1. **训练强度**：高强度训练需要更多碳水
2. **训练部位**：大肌群（腿、背）需要更多热量
3. **训练时间**：早晨/中午/晚上训练的餐食安排不同
4. **用户目标**：增肌/减脂/维持

## 示例

用户5月24日练背，当前热量摄入 750 kcal。

输出：
```markdown
**饮食建议 - 5月24日背部训练**

**训练前餐（训练前 2-3 小时）**
- 燕麦：80g，300 kcal
- 鸡蛋：3个，210 kcal
- 香蕉：1根，90 kcal
- 总热量：600 kcal

**训练后餐（训练后 30 分钟内）**
- 鸡胸肉：200g，330 kcal
- 糙米饭：200g，220 kcal
- 蔬菜：150g，50 kcal
- 总热量：600 kcal

**蛋白质摄入建议**
- 目标：70kg x 1.8g = 126g
- 当前：35g（早餐）
- 建议：午餐和晚餐各补充 45g 蛋白质

**水分补充建议**
- 训练前：500ml
- 训练中：200ml/15分钟
- 训练后：500ml

**注意事项**
- 背部训练强度大，确保碳水充足
- 训练后及时补充蛋白质
```
